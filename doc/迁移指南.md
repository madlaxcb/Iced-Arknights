# 迁移与升级指南

## 当前兼容基线

- Rust stable，最低版本 1.88。
- iced 精确锁定 =0.14.0；iced_futures 精确锁定 =0.14.0。
- iced_tiny_skia 为 0.14.1，scripts/check.sh 校验该版本。
- 使用自定义 HudTheme；自定义 Canvas 几何必须使用 canvas::Cache。详见 ADR-001/002/004。

## iced 0.14 项目约定

1. StyleFn 是装箱闭包；.class() 使用 Box::new(f) 并显式转换到 XxxStyleFn<'_, HudTheme>。
2. iced 布局宏会把子元素主题推断为 iced::Theme；使用 hud_widgets 同名宏或显式指定 HudTheme。
3. container Catalog 样式函数不带 Status；其他 Catalog 按 0.14 的 Status 变体匹配。
4. application(boot, update, view) 首参为启动函数，标题使用 .title()；主窗口 Id 经 window::oldest() 捕获。
5. Subscription::map/filter_map 映射闭包不得捕获；捕获状态时使用 iced_futures::subscription::filter_map 等带身份的订阅原语。
6. Animation<f32> 使用 interpolate_with；窗口帧、键盘和周期任务仅在需要时订阅。

## 升级流程

1. 在独立分支升级 iced 与 backend 锁版，检查 Cargo.lock，避免混合小版本。
2. 阅读新版本迁移说明与源码签名，更新 M0 API 备忘和相关 ADR。
3. 运行 scripts/check.sh，并对 Gallery / Sample App 做 tiny-skia 截图回归。
4. 复验多 Canvas、Cache 失效、键盘输入、窗口事件、表单控件、模态层、订阅启停和 Windows 交叉编译。
5. 记录差异与真 Windows 待验证项；验证通过前不更新兼容基线与发布包。

## 渲染后端约束

Live canvas Program 的多画布缺陷在 iced 0.14.1 tiny-skia 上仍可复现。静态几何复用 Cache，变化时明确失效；升级后重跑 P6 多画布对照，不以单画布截图替代。
