# HUD UI 设计规范

## 视觉原则

- 深色中性底、细边线、45° 切角；强调色只标识主操作和关键数据。
- 组件层级通过背景亮度、线条强度和文字层级表达；避免圆角、投影和渐变成为默认装饰。
- 状态颜色有语义：信息蓝、成功绿、警告黄、危险红；同时提供文字含义，不只依赖颜色。

## 颜色

主题颜色集中于 hud_tokens::Palette，组件不得重复定义字面色值。

| Token | 默认值 | 用途 |
|---|---:|---|
| bg0 | #0E0F11 | 窗口与页面底色 |
| bg1 / bg2 | #16181C / #1F2228 | 面板 / 悬停选中层 |
| line_dim/base/strong | #2C3037 / #3A3F47 / #5A606B | 分隔 / 常规边框 / 强调边框 |
| text_primary/secondary/disabled | #E6E8EB / #8A9099 / #555A63 | 正文 / 辅助 / 禁用 |
| accent | #FFD400 | 主操作与关键读数 |
| info/success/danger | #3FB6FF / #4ADE80 / #FF4D4F | 语义反馈 |

正文优先使用 text_primary；text_secondary 用于辅助信息。text_disabled 对比度不足，不可用于正常可读内容。对比度底线由 hud-tokens 单测约束。

## 间距与排版

- 间距基于 4px 栅格：xs/s/m/l/xl/xxl = 4/8/12/16/24/32px。
- 字号阶梯 xxs/xs/s/m/l/xl = 12/14/16/20/28/40px；说明文字不低于 12px。
- 数据数字使用等宽字体；双语标签中中文表达功能、英文用于短标识。
- 尺寸从 Tokens.geometry 与 Tokens.typography 读取，不散落魔法数。

## 几何、动效与可访问性

- 切角档位 s/m/l = 4/8/12px，保持 45°、无圆角；切角不得超过短边一半。
- 常规/强调线宽分别为 1/2px；自定义画布必须使用 canvas::Cache，见 ADR-004。
- 动效默认 120/200/280ms、ease-out；动画不可见或停止时取消帧订阅。
- 禁用态不能只靠颜色表达；浮层提供明确关闭路径；窄窗口下主内容可滚动。
