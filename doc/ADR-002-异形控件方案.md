# ADR-002：异形控件实现路线（R2 + R1，画布强制 Cache 写法）

- 状态：已接受（M0 结论；2026-10-04 依计划书 v0.2 与 P6 复验修订措辞）
- 关联：计划书 2.6 / 5.5（v0.2）、ADR-004、M0 预研报告

## 背景

iced 内置 quad 仅支持"矩形 + 圆角 + 边框"，切角外形需要自绘。候选：R1 Canvas 路径、R2 自定义 Widget、R3 Shader、R4 九宫格素材。

## 决策

1. **基础外形走 R2 + R1 组合**：`hud-core` 提供 `ChamferedBox` 自定义 Widget（布局/事件/命中），背景由 canvas 路径绘制；其余组件基于它组合。
2. **绘制一律经由 `canvas::Cache`（强制）**，禁用"每帧新建 Frame"的 Live 几何写法。
   - 性能层面：Cache 是缓存手段，尺寸/状态不变即不重绘（计划书 5.3）；
   - 正确性层面：**Cache 并非 #3452 的规避手段**（计划书 v0.2 明确），但 P6 复验
     （iced_tiny_skia 0.14.1）显示 Live 写法在多画布场景整体损坏、Cache 写法全部
     正确（证据与决策见 ADR-004）。因此本条同时是正确性约束与性能规范，根因
     修复依赖上游（#3452 修复不完整 / #3040），升级 0.15 时复验。
3. **内容保持矩形**，以 padding 避让切角；不对内容做斜切裁剪。
4. **命中测试规则**：切角区域属于背景装饰、不参与命中；可交互内容是叠加的真实 widget，其命中区即自身矩形。全库统一此规则并写入组件测试清单。
5. Shader 特效（R3）仅限可降级装饰，默认关闭。

## 依据（M0 + P6 实测）

- P1 原型在 tiny-skia 下：切角路径填充、1px 描边、2px 强调线像素正确；900×640 → 1200×760 缩放无错位（截图见 doc/）。
- 多画布缺陷复验（0.14.1，详见 ADR-004）：Cache 写法 4/4 正确，Live 写法 0/2 可见。

## 后果

- `ChamferedBox` 内部持有 `canvas::Cache`，仅在尺寸/状态变化时 `clear()`。
- 命中测试在自定义 Widget 中显式实现（四角切角三角形不命中），M3 配单元测试。
- 向 iced 上游报告 0.14.1 修复不完整；0.15 升级评估时以 `apps/proto` P6 对照页复验后再决定是否解除 Cache 强制。
